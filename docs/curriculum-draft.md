# 每日十五词 15주 내용 보강 초안

현재 주차마다 단어 10개와 예문 3개가 있습니다. 이 초안은 주차별로 **단어 10개와 예문 3개를 추가**하는 안입니다. 주차당 단어 20개, 예문 6개가 되어 듣기·문법·작문 수업이 각각 2시간 안팎을 채울 수 있도록 구성했습니다.

검토 포인트
- 병음 성조는 표준 표기이며, 교수님이 학습자 수준(HSK 1~3급)에 맞는지 확인해 주세요.
- 예문은 해당 주차의 문형을 반드시 한 번 이상 사용하도록 썼습니다.
- 가족·이름 등은 예시 인물(小明, 小红 등)로 적었습니다.

## 1주차 · 인사와 자기소개 (你好！)
문형: 我叫 + 이름 / 我是 + 국적

**추가 단어**
| 한자 | 병음 | 뜻 |
|---|---|---|
| 再见 | zàijiàn | 안녕히 가세요 |
| 谢谢 | xièxie | 고맙습니다 |
| 不客气 | bú kèqi | 천만에요 |
| 对不起 | duìbuqǐ | 미안합니다 |
| 没关系 | méi guānxi | 괜찮아요 |
| 老师 | lǎoshī | 선생님 |
| 朋友 | péngyou | 친구 |
| 中国 | Zhōngguó | 중국 |
| 韩国 | Hánguó | 한국 |
| 大家 | dàjiā | 여러분 |

**추가 예문**
- 你好，我是韩国人。 Nǐ hǎo, wǒ shì Hánguórén. — 안녕하세요, 저는 한국 사람입니다.
- 我叫小明，你叫什么名字？ Wǒ jiào Xiǎomíng, nǐ jiào shénme míngzi? — 저는 샤오밍이라고 합니다. 이름이 뭐예요?
- 认识你很高兴。 Rènshi nǐ hěn gāoxìng. — 만나서 반가워요.
